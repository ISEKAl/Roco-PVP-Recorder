# 洛克王国PVP对局录入系统

## 安装与运行

```bash
cd website
npm install
npm run dev
```

访问 http://localhost:3000

## 功能说明

### ✨ 智能推断功能
1. **第一回合自动满状态**：选择队伍后，第一回合所有精灵自动设为 HP=1, MP=10
2. **场下精灵状态继承**：添加新回合时，如果场上精灵没换，场下5只精灵状态自动继承上一回合
3. **简化输入**：只需要修改变化的精灵状态，其他保持默认

### 📋 功能特性
- 选择双方队伍（每队6只精灵）
- 回合导航（上一回合/下一回合）
- 添加/删除回合
- 录入每只精灵的 HP比例、能量
- 录入 Buff状态
- 选择行动：使用技能/更换精灵
- 导出JSON对局数据

## 数据格式

导出的JSON文件会保存到 `../raw_data/` 目录

```json
{
  "time": "2025-...",
  "winner": 1,
  "total_round": 2,
  "team_1": ["迪莫", "火神", ...],
  "team_2": ["魔力喵", "水蓝蓝", ...],
  "round": [
    {
      "cur_round": 1,
      "player_1": { ... },
      "player_2": { ... }
    }
  ]
}
```
