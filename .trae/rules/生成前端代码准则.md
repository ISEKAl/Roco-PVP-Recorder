1. 需要考虑布局美观，比如左右对齐，上下对齐等。
2. 需要考虑响应式布局，比如在不同屏幕尺寸下都能正常显示。
3. 需要考虑代码架构合理性。
4. 处理类型不匹配时，禁止使用 `as` 强制类型断言绕过 TS 检查。应使用 `typeof` 类型守卫（TypeScript 会自动收窄类型），无法收窄的场景应显式处理边界情况（如 return false / 抛出异常）。示例：antd Select 的 filterOption 回调中 option.children 类型为 `React.ReactNode`，不可 `as string`，应用 `typeof label === 'string'` 判断后再使用。
